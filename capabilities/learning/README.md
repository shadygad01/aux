# Learning Capability

Owns permanent capture of one evaluated outcome and its immediate hypothesis/evidence artifact through `LearningPort`. Input: `LearningRecord`. Output: optional `ResearchArtifact`. Metrics/logs cover stored records. Statistical research and proposals are excluded.

It also owns the independent Self-Critic boundary. Every official decision needs a pre-publication
critique; every outcome can be reviewed, and failures automatically open Research Tasks. See
`docs/self-critic-constitution.md`.
