# Research Capability

Owns cohort statistics through `ResearchPort` and canonical non-production proposals through
`ResearchProposalPort`. Outputs are `EdgeStatistics` and `ResearchProposal`. It cannot deploy,
approve production policy, or record outcomes.

It also owns Pattern Discovery research. Discovered patterns remain outside production until the
sequential significance, repeatability, backtest, forward-test, and documentation gates produce an
`INSTITUTIONAL_PATTERN`. See `docs/pattern-discovery-constitution.md`.

Its canonical proposal output is `ResearchProposal 1.0`, which requires every Research Governance
field and is structurally never production eligible. See `docs/research-governance.md`.
