🏗️ Monorepo Architecture

        
Modular decoupling with domain boundaries, contracts, and application isolation.

      


      

        

          
📁 capabilities/

          
Public business-first architecture exposing 10 independently replaceable capability interfaces (Collection, Evidence, Reasoning, Decision, etc.).

        

        

          
📁 apps/decision_cli/

          
Presentation and dependency-injection composition root powering command-line execution and JSON output formatting.

        

        

          
📁 packages/domain/

          
Immutable evidence models, decision records, named policy configurations, and strict domain invariants.

        

        

          
📁 packages/application/

          
Independent decision engine, trading opportunity engines, and external-effect application ports.

        

        

          
📁 packages/infrastructure/

          
Versioned JSON repository adapters, structured logging, and persistent append-only storage mechanisms.

        

        

          
📁 contracts/

          
Published JSON schemas defining exact interface specifications and schema migration rules.

        

      

    


    
    

      

        
📜 Constitutional Governance

        
Every evaluation is bounded by explicit institutional rules and fail-closed policies.

      


      

        

          
🛡️ Trading Constitution

          
Evaluates macro context, multi-horizon bias, dealing range location, liquidity sweeps, MACD, and news risk score (0–100).

        

        

          
⚖️ Self-Critic Engine

          
Requires pre-publication challenge, questions winning and failing decisions alike, and opens research tasks for failed decisions.

        

        

          
🔍 Trust Assurance

          
Exposes facts, lineage, contradictions, measurements, and canonical input fingerprints to guarantee complete auditability.

        

      

    


    
    

      

        
🗺️ Institutional Implementation Roadmap

        
Current development status and future progression phases.

      


      

        

          
Phase 0 (Current)

          
Governance Consolidation

          
Establish canonical concept ownership, ADR history, readiness restructuring, and 10 quality reviews. Feature development remains frozen.

        

        

          
Phase 1

          
Canonical Migration

          
Migrate Market Thesis, Trade Quality, Research Finding, and presentation projections without adding new trading behavior.

        

        

          
Phase 2

          
Durable Controls

          
Replace in-memory governance, research, pattern, critique, and health records with durable, hash-bound SQLite stores.

        

        

          
Phase 3

          
Research Baseline

          
Measure abstention, calibration, explanation completeness, source quality, and decision quality trends.
