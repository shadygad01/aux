# Documentation

This folder owns system-wide architecture decisions, hypothesis governance, dependency review, error behavior, and migrations. Package-specific interface notes remain beside their packages so implementation and contracts are reviewed together.

Governing entry points:

- `roadmap.md` — implementation freeze, phases, and exit evidence.
- `adr/` — architecture decisions.
- `concept-ownership.md` — canonical objects, projections, and adapters.
- `lineage-contract.md` — canonical provenance path.
- `technical-debt-register.md` — one debt system of record.
- `institutional-health-dashboard.md` — canonical health metrics and baseline.
- `architecture-entropy-report.md` — hostile repository audit.
- `governance-consolidation-report.md` — sprint verdict and readiness score.
